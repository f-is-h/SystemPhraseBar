# Changelog

## 1.0.0 — 2026-10-15

- Manage the Text Replacements built into macOS: search, add, edit and delete phrases.
- Open the compact panel with either mouse button; access settings and About from the `…` menu.
- Native Liquid Glass on macOS 26+, with a vibrant fallback on older macOS, larger text and subtle row dividers.
- Automatically use Chinese for a Chinese primary system language and English for all other languages.
- Launch at login, enabled on first launch, with a switch to turn it off.
- Lightweight GitHub update checks and a repository link, without an updater framework.
- Back up before changes and retain the latest 20 app backups; reject duplicate and stale edits and verify saved changes.
- Original app icon and monochrome menu bar template; universal Apple Silicon/Intel `.app.zip` distribution.
